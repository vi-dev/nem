Enable configured catalogs.

Include the named catalogs in lookups again, in the place they kept while disabled.

## Usage

```shell
nem catalog enable <name>...
```

## Examples

```shell
nem catalog enable official         # resolve from it again
```

## Global flags

`--color`, `--quiet`, and `--verbose` apply to every command; see [nem](../nem/).
