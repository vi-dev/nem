Manage this nem installation.

Commands that act on the nem binary itself rather than on a project.

## Usage

```shell
nem self
```

## Examples

```shell
nem self update              # update nem
```

## Commands

| Command | Description |
|---------|-------------|
| [update](../nem-self-update/) | Update nem to the latest build on its channel |

## Global flags

`--color`, `--quiet`, and `--verbose` apply to every command; see [nem](../nem/).
