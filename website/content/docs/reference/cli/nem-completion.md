Generate the autocompletion script for the specified shell.

Generate the autocompletion script for nem for the specified shell.
See each sub-command's help for details on how to use the generated script.


## Usage

```shell
nem completion
```

## Commands

| Command | Description |
|---------|-------------|
| [bash](../nem-completion-bash/) | Generate the autocompletion script for bash |
| [fish](../nem-completion-fish/) | Generate the autocompletion script for fish |
| [powershell](../nem-completion-powershell/) | Generate the autocompletion script for powershell |
| [zsh](../nem-completion-zsh/) | Generate the autocompletion script for zsh |

## Global flags

`--color`, `--quiet`, and `--verbose` apply to every command; see [nem](../nem/).
