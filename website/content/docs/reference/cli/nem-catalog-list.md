List configured catalogs.

Print every configured catalog in precedence order with its type, source, and status.

## Usage

```shell
nem catalog list
```

Aliases: `ls`

## Examples

```shell
nem catalog list             # precedence order, first wins
```

## Global flags

`--color`, `--quiet`, and `--verbose` apply to every command; see [nem](../nem/).
