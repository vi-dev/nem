Print the version of nem.

Print the version of this nem binary together with its release channel, build time, commit, Go version, and platform.

## Usage

```shell
nem version
```

## Examples

```shell
nem version                  # full build information
nem --version                # the version string alone
```

## Global flags

`--color`, `--quiet`, and `--verbose` apply to every command; see [nem](../nem/).
